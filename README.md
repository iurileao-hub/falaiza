# Ouvidoria Participa DF — PWA Acessível

> 🏆 Projeto para o **1º Hackathon em Controle Social: Desafio Participa DF**
> 📂 Categoria II: Ouvidoria

## Objetivo

Desenvolver uma Progressive Web App (PWA) acessível para o sistema Participa DF, permitindo que cidadãos registrem manifestações de ouvidoria através de múltiplos canais (texto, áudio, imagem e vídeo), com acessibilidade plena e opção de anonimato.

## Status

🚧 **Em planejamento** — Estrutura inicial do projeto

## Funcionalidades Planejadas

- [ ] Registro de manifestações por texto
- [ ] Gravação e envio de áudio
- [ ] Upload/captura de imagens
- [ ] Upload/gravação de vídeo
- [ ] Emissão automática de protocolo
- [ ] Opção de anonimato
- [ ] Acessibilidade WCAG 2.1 AA
- [ ] PWA instalável (offline-first)
